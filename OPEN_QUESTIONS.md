## ✅ Recently Resolved Decisions (Archived)

- [x] **Dice System:** Pure d6 only. Standard roll = 1d6 + Attribute vs SG (4, 6, 8, 10). Advantage/Disadvantage = 2d6 pick highest/lowest.
- [x] **5 Attributes:** Kraft (KRA), Geschick (GES), Zähigkeit (ZÄH), Verstand (VER), List (LIS) — scores 0 to 3.
- [x] **LP Formula:** `LP = ZÄH × 2 + 6` (Berserker 12, Kriegstänzerin 10, Goblin 8, Magierin 8).
- [x] **Party Size:** Always 4 heroes per scenario (2 players control 2 heroes each).
- [x] **Item & Deck System:** 
  - Physical cards for everything in **Mini-Euro format (44 × 68 mm)**.
  - 12 Starting Equipment cards (3 per hero, marked with `◈`).
  - 36 Equipment Loot/Market cards.
  - 18 Ereigniskarten (Event Deck).
  - Strict carrying limit: 1 Armor, 2 Hands, 1 Accessory, 3 Backpack slots (max 7 cards).
- [x] **Magic Resource:** 5-box Erschöpfungsleiste (Fatigue Track) for Magiegelehrte with 6 core spell cards.
- [x] **Goblin Drunk Magic:** 1d6 table triggered by drinking liquor, utilizing a 3-box fatigue track.
- [x] **Monster AI:** Automated 3-step priority targeting for GM-less co-op play.
- [x] **First Playable Scenario:** Scenario 01 "Die verfluchte Krypta von Dun-Karr" complete with 4 rooms and mini-boss.
- [x] **Production Format:** Switched from modular laser-cut tile system to **wire-bound A4 Game Book** (Scenario Book). All 5 scenarios live in one spiral-bound book; maps printed full-page at 300 DPI. *(Decided Session 7 — 2026-11-04)*
- [x] **Print Document Format:** Final print files generated as **Word/LibreOffice `.docx`** documents (A4, left page = instructions, right page = battle map). Print directly from Writer/Word in one pass. *(Decided Session 7 — 2026-11-04)*
